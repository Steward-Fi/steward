# .impeccable.md — Steward design context

## Design Context

### Users
Engineers and technical founders deploying AI agents that touch real systems: money, credentials,
production APIs. Secondary: security-conscious operators and enterprise platform teams evaluating
an authority layer for autonomous systems. They arrive skeptical, technically fluent, and allergic
to marketing gloss. The job to be done: "can I trust this thing to hold authority my agent must
not hold itself, and can I verify that claim in the code?"

### Brand Personality
Sovereign, precise, calm. Three words: **guarded, engineered, open.**
The interface should feel like well-machined security hardware: nothing decorative, everything
load-bearing. Emotional target: the quiet confidence of a vault door, not the flash of a fintech
landing page. Steward is the adult in the room where agents act at machine speed.

### Aesthetic Direction
- Dark, warm-tinted near-black base (#0b0a09 family) with ONE amber/burnt-orange accent
  (oklch 0.75 0.15 55). No second accent. No purple/blue AI palette. Ever.
- Typography: Hanken Grotesk (display + body, self-hosted) + JetBrains Mono for code/data/labels.
  Tight tracking on display sizes. Hierarchy through weight and color, not scale screaming.
- Layout: asymmetric, left-aligned, editorial. Split heroes, sticky side rails, varied rhythm.
  Banned: 3-equal-card feature rows, centered hero text, card grids as default filler.
- Texture: hairline borders (1px, warm gray), grid-line ghosts, generous negative space.
  Cards only when elevation means something. Prefer border-t / divide-y logic grouping.
- Motion: restrained, load-in staggers + scroll reveals with expo easing; transform/opacity only.
  One well-orchestrated hero entrance beats scattered micro-interactions. Respect reduced-motion.
- Code blocks are first-class brand surfaces: real, runnable-looking SDK calls, warm syntax theme.
- Numbers and technical specs in mono. Data is the decoration.

### Anti-references
Generic AI-startup slop: neon glows, glassmorphism everywhere, gradient text, purple-to-blue,
Inter-everything, centered everything, bento-for-bento's-sake, "Elevate/Seamless/Unleash" copy.
Also: consumer-fintech friendliness. Steward is infrastructure, not a neobank.

### Voice
Lowercase-adjacent, declarative, zero hype. Concrete verbs. Short sentences that carry weight.
"Give agents power without giving them the keys." No em-dashes. No exclamation marks.
Positioning: the open authority and execution layer for AI agents. Vendor-neutral by principle
(any model, any runtime, any cloud, any chain). Anti-Privy is a comparison-page argument,
not the hero.

### Design Principles
1. **Authority is the product.** Every visual choice should reinforce custody, policy, proof.
2. **Show the boundary.** The intent → policy → execution → audit pipeline is the brand diagram.
3. **Real code, real receipts.** Demos use actual SDK surface and plausible data, never lorem.
4. **One accent, earned.** Amber marks the decision points (allow/deny, sign, freeze). Nothing else.
5. **Open by design.** Self-hosted fonts, no trackers, works without JS where possible. The page
   itself should embody sovereignty.
